## 學習目標

這一課要建立 Windows Process（行程）的基本模型。你會知道行程與執行緒的差別、使用者模式與核心模式的邊界，以及為什麼 Windows API 不是一般函式庫呼叫那麼簡單。

## Process 不是一個「正在執行的程式檔」

Process 是作業系統提供給執行中程式的一個隔離環境。同一個 `notepad.exe` 可以同時啟動多個行程；它們共用磁碟上的程式檔，但不會自動共用記憶體、控制代碼或執行狀態。

一個 Windows 行程通常包含：

- 一組虛擬位址空間（virtual address space）。
- 至少一個執行緒（thread）。
- 控制代碼表（handle table），記錄可操作的物件。
- 安全性權杖（access token），描述執行身分與權限。
- 載入的模組、堆積、環境變數與其他作業系統狀態。

Thread 是 CPU 排程的基本單位。多個執行緒可以存在於同一行程，通常共享該行程的虛擬位址空間；Process 則提供較強的隔離邊界。

| 比較項目 | Process | Thread |
|---|---|---|
| 隔離邊界 | 較強，通常有獨立虛擬位址空間 | 同一個 Process 內的 Threads 通常共享位址空間 |
| 排程單位 | 本身擁有執行所需的資源容器 | CPU 排程通常以 Thread 為單位 |
| 失敗影響 | 一個 Process 終止時，其他 Process 可繼續執行 | 錯誤的共享記憶體操作可能影響同一個 Process |
| Handle 與權限 | 有 Process Handle 與存取權限 | Thread Handle 與 Process 權限仍需分別檢查 |

## 使用者模式與核心模式

應用程式大多在**使用者模式（user mode）**執行。它不能直接任意讀寫其他行程的記憶體，也不能直接操作硬體。需要建立行程、開啟檔案或配置記憶體時，程式會透過 Windows API 進入作業系統核心。

例如 `CreateProcessW` 是 Win32 API。程式呼叫它之後，控制權會跨越使用者模式與核心模式的邊界。核心檢查呼叫者權限，完成必要工作，再把結果與控制代碼交回使用者模式。

這也是為什麼 API 名稱不代表所有細節：`OpenProcess` 成功與否，取決於呼叫者是否被允許取得目標行程的控制代碼，以及要求的存取權限是否合理。

## 一個最小概念範例

```cpp
#include <windows.h>

STARTUPINFOW startup{};
PROCESS_INFORMATION process{};
startup.cb = sizeof(startup);

BOOL ok = CreateProcessW(
    L"C:\\Windows\\System32\\notepad.exe",
    nullptr,
    nullptr,
    nullptr,
    FALSE,
    0,
    nullptr,
    nullptr,
    &startup,
    &process
);
```

這段程式碼只展示 API 的形式。正式程式必須處理 `ok == FALSE`、關閉不需要的 `hProcess` 與 `hThread`，並根據實際路徑與權限設計錯誤處理。

## Handle 是權限的門票

Handle（控制代碼）是使用者模式程式指向核心物件的一個識別值。Process、Thread、File、Event 都可能是核心物件。Handle 不是物件本身，也不是可以任意傳給其他程式的萬用通行證。

作業系統在建立 Handle 時會記錄允許的存取權，例如查詢狀態、讀取記憶體或等待結束。即使兩個程式都拿到同一個行程 ID，也不代表它們擁有相同的操作權限。

## 真實應用與資安意義

程序監控工具會追蹤新行程的建立、父行程關係與命令列。端點防護則可能檢查 `CreateProcessW` 的參數、執行檔簽章與父行程是否合理。

另一方面，惡意程式可能嘗試開啟其他行程、注入程式碼或提升權限。防守方需要同時看行為、身分與權限，不能只看一個 API 名稱就判定安全或惡意。

## 今日重點整理

- Process 是隔離的執行環境，Thread 是 CPU 排程單位。
- 多執行緒通常共享行程位址空間，但不同行程彼此隔離。
- Windows API 常需要跨越使用者模式與核心模式邊界。
- Handle 伴隨存取權限；知道 ID 不代表有權操作物件。

## 延伸思考

如果兩個程式都以同一個 Windows 使用者身分執行，是否一定有相同的權限？權杖、完整性等級、群組成員、AppContainer 與其他安全機制都可能造成差異。
